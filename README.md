# Лабораторные работы по операционным системам

Среда выполнения — Linux, в том числе Ubuntu в WSL 2.
Программы написаны на C17 и используют POSIX API.
Тесты написаны на C++17 с Google Test.

Каждая лабораторная работа располагается в отдельной папке
и собирается своим Makefile.

| Работа | Вариант | Тема |
| --- | --- | --- |
| [Лабораторная работа 2](lab02/README.md) | 7 | Процессы, перенаправление потоков и неименованный канал |
