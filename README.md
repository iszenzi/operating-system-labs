# Лабораторные работы по операционным системам

Среда выполнения — Linux, в том числе Ubuntu в WSL 2.
Программы написаны на C17 и используют POSIX API.
В ЛР №2 есть тесты на C++17 с Google Test.

Каждая лабораторная работа располагается в отдельной папке
и собирается своим Makefile.

| Работа | Вариант | Тема |
| --- | --- | --- |
| [Лабораторная работа 2](lab02/README.md) | 7 | Процессы, перенаправление потоков и неименованный канал |
| [Лабораторная работа 3](lab03/README.md) | 7 | Потоки POSIX и моделирование игры в кости |

## Структура репозитория

```text
operating-system-labs/
├── .gitignore
├── README.md
├── lab02/
└── lab03/
```

В папке каждой работы находятся Makefile, README, include, src и report.
Каталоги build и artifacts создаются при сборке и проверках и исключены из Git.
Для ЛР №3 скрипт замеров находится в scripts, результаты исследования — в BENCHMARK.md.
