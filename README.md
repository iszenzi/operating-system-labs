# Лабораторные работы по операционным системам

Среда выполнения: Ubuntu в WSL 2. Язык программирования: C.

Каждая лабораторная работа располагается в отдельной папке и собирается своим Makefile.

| Работа | Вариант | Тема |
| --- | --- | --- |
| [Лабораторная работа 2](lab02/README.md) | 7 | Процессы, перенаправление потоков и неименованный канал |

Сборка второй лабораторной из корня репозитория:

```sh
make -C lab02
```
